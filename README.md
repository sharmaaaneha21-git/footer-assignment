Responsive Footer Assignment 🌐

This project is a **responsive website footer** built using **HTML and CSS** as part of a **LetsUpgrade assignment**.  
The footer is designed with a clean layout and modern UI, focusing on responsiveness and usability.

🚀 Features
- Clean and modern footer design
- Responsive layout for mobile and desktop screens
- Quick navigation links
- Contact information section
- Social media links with Font Awesome icons
🛠️ Technologies Used
- HTML5
- CSS3
- Font Awesome Icons
